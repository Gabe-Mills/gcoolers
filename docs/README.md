# `docs/` is not gcoolers.com

GitHub Pages for **gcoolers.com** is served from branch `gh-pages`, built from the
private repo **`Gabe-Mills/gcoolers-website`** (Astro source of truth).

Files here are leftovers / install helpers only. Do not treat `docs/index.html`
as the marketing site, and do not point Pages at `/docs` on `main`.

| Role | Repo / branch |
| --- | --- |
| Website source | `Gabe-Mills/gcoolers-website` (`main`) |
| Published static | `Gabe-Mills/gcoolers` (`gh-pages`) |
| Live | https://gcoolers.com |
