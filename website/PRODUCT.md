# Product

## Register

brand

## Users

Mac owners on Apple Silicon who run hot under load (dev, video, AI, gaming) and want quieter fans, cooler chassis, and less thermal panic without babysitting system settings.

## Product Purpose

Gcoolers is an Apple Silicon thermal governor: always-on daemon, menu bar app, profiles (quiet / balanced / cool), and learning bias. gcoolers.com is the public face: explain the product, drive GitHub + Homebrew install, and collect support / donations.

## Brand Personality

Cool, precise, kinetic. Feels like a living thermal instrument on the Mac, not a generic SaaS landing page. Confidence from real hardware behavior (temps, fans, profiles), not buzzwords.

## Anti-references

Not purple-gradient AI SaaS. Not cream/terracotta lifestyle. Not dense newspaper editorial. Not Venmo-first tip jars. Not stock “MacBook on desk” hero clichés without a product signal.

## Design Principles

1. Show the instrument: temperatures, fans, and profiles are the visual language.
2. Motion proves the product is alive; static screenshots alone feel dead.
3. Brand first: “Gcoolers” owns the first viewport.
4. Install is honest: real GitHub + Homebrew commands, no fake “coming soon” CTAs.
5. Support is human: one email, clear donation options, no Venmo.

## Accessibility & Inclusion

WCAG AA contrast minimum. Respect `prefers-reduced-motion` with fades or static states. Keyboard-reachable nav and donate links. Body copy readable on dark surfaces.
