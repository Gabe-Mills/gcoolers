Questions

Does it need kernel extensions?

No. Gcoolers runs in user space and talks to the standard fan and sensor interfaces.

Will it void anything?

No. Every profile stays inside Apple's own fan limits — Gcoolers only shapes the curve inside them.

Which Macs?

Apple Silicon Macs on macOS 13 and later. Fan control applies to models that have fans; sensors and profiles work everywhere.

How do I remove it?

Run gcoolers uninstall, then brew uninstall gcoolers. Nothing is left behind.
